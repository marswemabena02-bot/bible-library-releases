# Bible Library Android updates

This public repository contains signed Android update packages for the Bible Library app.

- `update.json` is the update manifest checked by the installed app.
- `BibleLibrary-v*.apk` files are signed installation packages.
- The application source code and signing credentials are kept separately in a private repository.

Install a newer APK over the existing Bible Library app to retain reading progress, notes, bookmarks, highlights, plans, and history.
